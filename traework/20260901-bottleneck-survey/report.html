1. TL;DR

基于 2026-08-24 难例挖掘的量化分解，当前 SSDC-UAV 上 YOLO12s 的性能缺口可以归结为 三个相互独立的问题，其余候选解释（NMS、切片边缘、重复检测、P2 覆盖）均已被证据排除：

B1 · 难样本判别力 / 置信度抑制Recall 主瓶颈

小目标 + 密集 + 重叠场景下，分类/置信度分支系统性低估。2190 个漏检中 2073 个（94.7%）是低分漏检——框已框出（IoU≥0.5），分数中位数仅 0.123。

+4.58 AP50Oracle 仅修复打分排序的上界（R 0.806→0.990）
B2 · 边界框回归精度mAP75 主瓶颈

9073 个 TP 中 3347 个（36.9%）IoU 卡在 [0.5, 0.75)，只差几个像素。小圆框宽高比退化 + 密集粘连是主因。

+27.2 AP75Oracle 完美定位上界（0.607→0.880）
B3 · 背景判别与标注噪声Precision + 评估可信度

332 个高分（≥0.5）背景误检疑似漏标/标注噪声；全分数段 24541 条背景预测。既压 Precision，又污染评估口径。

+2.22 AP50Oracle 清除全部背景 FP 上界（P→0.911）

排除清单（带证据，不再投入）

NMS 策略：GT-GT IoU≥0.7 仅 0.036%，重复框仅 127 个（Oracle +0.16）；放松 NMS 全面变差；收紧 iou=0.5–0.6 已免费拿到 +0.4~0.5 mAP50。Soft-NMS/密度感知 NMS 已证伪。
切片边缘效应：边缘区域 FN 率与内部无显著差异（阴性结果）。
P2 极小目标覆盖：极小目标占比仅 0.24%，P2 实验 -0.26 mAP50。
推理分辨率 / TTA：imgsz960 与 TTA 均负收益——瓶颈在训练期判别力，不在推理分辨率。

Top 3 推荐（详见第 4、5 节）

重点卡片 · Varifocal Loss CVPR 2021 Oral 损失

机制
训练分类分支直接预测 IACS（IoU-Aware Classification Score）：正样本标签 = 预测框与 GT 的真实 IoU（软标签），负样本以 focal 形式非对称降权（α=0.75, γ=2.0）。
为什么对症
B1 的本质是"定位合格（IoU≥0.5）但分数被压到中位数 0.123"。VFL 让这类框获得 0.5–0.8 量级的监督目标而不是被当负样本压低——直接修复打分口径。原文动机实验：仅把分类目标换成 gt_IoU，排序性能即从 56.1 → 74.7 AP。
场景实证
IEEE TGRS 低空航拍密集小行人检测以 VFL 替换 focal loss 报告提升；农业刊 NVW-YOLOv8s（CEA 2024）用 VFL+WIoU 在番茄小目标/遮挡场景 mAP50 +4.8%。
为什么这次不一样
本项目历史增益最大来源就是损失函数级改动（Focaler-CIoU +0.389 为史上最佳）；但已试的全部是回归侧 IoU 损失，从未动过分类侧打分口径——而 B1 恰恰是分类/置信度分支的问题。

重点卡片 · CrowdAug AAAI 2023 增强

机制
诊断拥挤场景两大病因：ICD（IoU-置信度相关性被拥挤扰乱）与 CDD（NMS 去重混淆）；用专门制造拥挤重叠构型的 copy-paste 让检测器在训练期学会拥挤。
为什么对症
本项目 GT-GT 重叠 [0.5,0.7) 区域 FN 率高达 41.8%，正是 ICD 的表现——重叠苗株被分类分支系统性压低。CrowdAug 可控粘贴制造该 IoU 区间的重叠对，使模型学到"重叠≠低分"。
场景实证
拥挤行人基准上 Faster R-CNN +2.2 AP、RetinaNet +3.3 AP；甘蔗苗行内拥挤与其场景同构。Ultralytics 已内置 copy-paste 基础设施，改造成本低。

重点卡片 · 为什么还需要新的 IoU 损失？（Inner-IoU / MPDIoU / EIoU）损失

历史教训
已试 4 个 IoU 变体（Focaler/PIoU2/WIoUv3/Slide）增益都在噪声地板 σ≈0.10 附近——它们都仍在"IoU 框架 + 聚焦权重"内打转，没有触及两个真正的卡点。
卡点一：宽高比退化
甘蔗苗框近圆（宽高比≈1）："宽高比相同但尺寸不同"时 CIoU 的 v 项≈0、丧失梯度，回归停滞在 0.5–0.75 带。EIoU（独立 w/h 惩罚）与 MPDIoU（角点距离）在该退化情形下仍有梯度。
卡点二：高 IoU 样本梯度不足
3347 个 [0.5,0.75) 带样本需要的是"继续精修"的信号。Inner-IoU 用辅助内框放大高 IoU 样本的回归梯度，且是 wrapper——可直接叠加在已验证有效的 WIoUv3 上（Wise-Inner-IoU），与历史投入不浪费。
评估纪律
B2 实验以 mAP75 为主选指标（mAP50 已近饱和），每方案 ≥2 种子对照噪声地板。

重点卡片 · Confident Learning 标注审计 JAIR 2021 数据流程

机制
用交叉验证预测概率与给定标签估计噪声联合分布，输出噪声样本排序/剪枝清单；与模型、模态完全解耦（开源 cleanlab）。
为什么优先
B3 的 +2.22 上界里混着两种成分：真背景误检（模型问题）与漏标（数据问题，332 个高分疑似）。不先审计就无法知道该修模型还是修数据——而且漏标同时污染训练（把真苗当背景学）与评估（AP 被低估）。这是唯一能同时提升性能与评估可信度的动作，成本最低。
配套范式
NWD-RKA 原文（ISPRS 2022）正是"专家复核重标 AI-TOD → AI-TOD-v2 + 度量改进"双管齐下的模板案例。

4. 推荐矩阵（去重 × 已试清单映射 × 排序）

排序标准（用户口径）：① 对 B1 的 Recall 空间是否 ≥ +1.0 mAP50 量级；② 预训练兼容（插件式损失/增强/数据 > 小模块 > head 重构）；③ 实现成本。全部候选均与"已试过清单"核对：没有推荐任何已证伪方向（NMS 系、P2、颈部/head 重构、内注意力）。

3NWD 混合（小框 NWD + 大框 CIoU）B1B2B3ISPRS J P&RS 2022损失/分配高低未试度量层换血而非 IoU 框架内调权；已试 4 个 IoU 变体均未触及"小框 IoU 对位移过敏"这一根因。
4CrowdAug 拥挤增强B1AAAI 2023增强高中未试密度/重叠构型的训练供给问题从未被干预过（历史全是结构/损失改动）；ICD 机理与 [0.5,0.7) 重叠区 41.8% FN 直接对应。
5Inner-IoU wrapper（叠加 WIoUv3）/ MPDIoU / EIoUB2arXiv / Neurocomputing Q1损失高低未试针对宽高比退化与高 IoU 梯度不足两个新卡点，与已试聚焦型 IoU 机理正交；Inner 可直接叠加在史上最佳 WIoUv3 上。
6BPC 校准损失B3CVPR 2023辅助损失高低中未试"高分但错"首次有专门的损失项；与审计结论联动（若误检以真背景为主则收益更大）。
7GFLv2-DGQP（LQE）B1B2NeurIPS 2021小模块+损失中中未试与 VFL 互补的第二条打分修复路径（从回归分布推断定位质量）；YOLO 头已输出 DFL 分布，取统计量方便。
8ELDET / DN-TOD（噪声鲁棒训练）B3NeurIPS 2025 / PR 2026策略/数据高中未试若审计证实标注噪声显著，这是 2025–2026 最新的检测噪声鲁棒 SOTA，机理（截断记忆化/类别漂移过滤）与漏标成因对口。
9OHEM 难例加权B1CVPR 2016策略高低未试本项目难例占比极高（94.7% FN 为低分漏检），难例加权的收益条件好；注意配合置信度过滤防噪声标签。
10Alpha-IoU（α 幂族）B2B3NeurIPS 2021损失高低未试唯一显式针对"噪声框标注"鲁棒的 IoU 损失——粘连框的脏边界正是 B2/B3 交集。
11Simple Copy-Paste（密度供给）B1CVPR 2021增强高中未试CrowdAug 的通用版；Ultralytics 已内置 copy_paste 参数，可作为低成本先行试验。
12TAL 超参扫描（topk/α/β）B1B2ICCV 2021 Oral策略高零已内置零成本调优项，可与任何实验并行。
不推荐清单（与本项目失败原因冲突）：TOOD T-Head / GFLv2 之外的 head 重构（权重断裂史）；Softer-NMS（需方差头 + 自定义 NMS，与免 NMS 趋势及已证伪的 NMS 改动方向冲突）；AODet 完整框架（DETR 系，集成成本高）；DCFL 完整版（工程量大，仅借鉴"粗阶段保底正样本配额"思想）；SNIPER 完整管线（用简化多尺度版替代）。

复盘总结：历史改动 90% 集中在 B2 的 IoU 框架内与无差别结构增强，而最大的两块可回收空间——B1 的打分口径（+4.58 上界）与 B3 的数据质量（+2.22 上界）——从未被真正干预过。本报告的 5 组实验全部指向这两块空白。

7. 场景证据：甘蔗苗 / UAV 农业交叉文献

补充检索确认"甘蔗苗/作物苗 UAV 检测 + 计数"是 2024–2026 活跃研究方向，且同类工作的 Recall 水平（90–96%）高于本项目基线（81.3%），说明存在可追平的空间：

  • 蔗田缺苗自动获取（南方农业学报 2025）：YOLOv8 地块尺度蔗苗检测，准确率 98.84%、召回率 90.76%、mAP 97.05%，杂草遮挡下仍稳健。
  • YOLOv7-SSC 甘蔗苗检测（国家科技期刊平台 2025）：准确率 95.1%、召回率 96%、mAP 94.4%，8.79 fps 边缘部署。
  • 中耕期甘蔗植株检测计数（改进 YOLOv5s，万方 2025）：针对叶片遮挡、目标粘连、复杂背景，用归一化注意力抑制相似杂草背景——与本项目 B1/B3 同构。
  • CGMap（arXiv 2607.18779）：YOLOv8 + UAV 甘蔗发芽计数与缺苗制图，印度多农业气候区数据。
  • Li-YOLOv9 水稻苗（IEEE 遥感刊 2025）：大规模无人机遥感水稻苗轻量化检测，边缘计算导向。
  • Maize-YOLOv8n 玉米苗漏检（Front. Plant Sci. 2025）：专门以"漏检"为主诉的苗期检测工作。
  • YOLO11 柑橘跟踪计数（农业工程学报 TCSAE 2025/26）：UAV 视频流检测+ByteTrack 计数，检测头简化三层。
  • 综述兜底：Small Object Detection 综合综述（arXiv 2503.20516，覆盖 2024–2025 Q1 刊）；UAV 小目标检测综述（IEEE 2025，"Advances and Open Challenges in Small Object Detection for UAV Imagery"）——均把低分辨率细粒度特征丢失、背景干扰、密集遮挡列为核心挑战，与 B1/B2/B3 归结一致。
