一、总体战略

decision-summary
一句话结论：瓶颈不在骨干架构，而在数据侧（标注质量 + 难样本置信度）与后处理。论文应以 s 尺寸 YOLO12 为基线、统一 from-scratch 协议，围绕"密集漏检、小苗漏检、打分校准、重复框"四个实证问题做四层级改进，并用计数指标（R²/MAE）作为差异化贡献。
决策项结论一句话理由
COCO 预训练主协议不加载 统一 from-scratch结构改进断裂权重迁移，混用协议不可比；从零仅低 0.15pp
模型尺寸s 为主基线，n 作对照39 组语料全在 s；s 与 n 仅差 0.39pp

二、问题 1 · 是否加载 COCO 预训练权重？

Q1
结论：主实验协议统一不加载（from scratch），并在论文中附一张两行协议对照表说明理由。
证据（测试集 mAP50）数值 / %含义
YOLOv12s + COCO 预训练 150ep88.267预训练基线
YOLOv12s from-scratch 150ep87.933从零仅低 0.33pp
YOLOv12s from-scratch 300ep88.121从零仅低 0.15pp
Focaler-CIoU（预训练协议）88.656 (+0.39)历史最佳"改进"
Focaler-CIoU（from-scratch 协议）87.932 (+0.00)改进效应与协议交互！
  1. 公平性：结构性改进会断裂预训练权重迁移——加载预训练会系统性偏袒损失类改进、惩罚结构类改进，消融结论不可信；
  2. 数据充分性：训练集 10,707 图 / 66,420 框，从零训练与预训练差距仅 0.15pp，无需借 COCO 先验；
  3. 反例警示：Focaler-CIoU 的 +0.39pp 在 from-scratch 下归零——混用协议的实验互相不可比（历史 39 组实验的主要方法学隐患）；
  4. 文献先例：《改进YOLOv12n的PCB缺陷检测》（电子测量与仪器学报 2026）显式声明"统一超参 + 不用预训练权重"；
  5. 论文写法：试验节放协议对照表（88.267 vs 88.121），声明"为保证结构改进与损失改进的对比公平性，本文统一采用从零训练协议"。

  1. 实验语料连续性：39 组改进实验全部在 s 上，模块行为认知（哪些有效/失败）都建立在 s 上，换 n 等于推倒重来；
  2. 精度差距小：0.39pp 的差距本身可写成论文"尺寸选型"小节的实证素材；
  3. 论文写法：方法节写明选型理由（期刊审查点）——"综合考虑检测与计数精度需求及计算成本，选用 s 尺寸；并给出 n 尺寸对照验证尺寸鲁棒性"；
  4. 加分项：若有 Jetson 等设备，用 n 尺寸 + 最终改进做部署实测（FPS）——部署用 n、主实验用 s，各自交代清楚，不冲突。

五、问题 4 · 如何判断瓶颈在数据还是算法？

Q4

5.1 五步判别框架（通用方法论）

  1. 误差分解（Oracle 分析）：FN/FP 分类 → 模拟修复后的 AP 增益，找最大杠杆错误类型；
  2. 架构敏感性试验：统一协议换 N 种架构变体，全在噪声带内 → 架构非瓶颈；
  3. 标注审计实验：人工复核可疑 FP/FN → 修订重训，mAP 显著上升 = 标注质量瓶颈；
  4. 数据规模实验：25%/50%/75% 子集 scaling 趋势，未饱和 = 数据量瓶颈；
  5. 人类上限 / 交叉验证：界定"还能涨多少"。

5.2 本案已完成的判别（测试集 11,263 个 GT）

发现数值指向
低分漏检占全部漏检2,073/2,190 = 94.7%打分/难样本问题，不是"看不见"
完全未定位漏检6 个（0.05%）特征提取够用 → 骨干非瓶颈
修复低分漏检 Oracle 上界AP50 +4.58pp最大杠杆在打分校准
背景抑制上界+2.22pp332 个高分 FP 疑似漏标 → 数据侧
定位质量上界AP75 0.607→0.880回归质量约束 mAP50-95
漏检率 × 尺度小苗 46% vs 大苗 9.5%上采样 / 小目标通路
漏检率 × 密度16.4% → 50%密集友好损失 / 后处理
架构敏感性（39 组）最好 +0.39pp，噪声带 0.16pp架构收益逼近统计噪声下限
本案结论：瓶颈主要在数据侧（标注质量 + 难样本置信度）与后处理策略，而非骨干架构。依据：39 组架构变体全部落在噪声带附近；94.7% 漏检是"框出来了但分数低"；332 个高分误检目测为真实幼苗；漏检率与物理因素（尺度/密度）强相关，需靠数据质量与针对性损失/后处理缓解。
