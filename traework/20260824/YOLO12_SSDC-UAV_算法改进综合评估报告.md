# YOLO12s 甘蔗幼苗检测（SSDC-UAV）算法改进综合评估报告

- 生成日期：2026-08-24
- 评估范围：`runs/test_result/SSDC-UAV_Test_Result.csv`（39 组实验）、17 个训练目录的 `train.log` 权重迁移记录、`datasets/SSDC-UAV_coco` 标注统计、`scripts/improved_train` 全部训练脚本
- 判定标准（用户提供）：mAP50 提升 ≥ 1.0 个百分点，且 Precision 与 Recall 不得同时下降；漏检（FN）代价高于虚警（FP），优先保证 Recall

---

## 1. 执行摘要

1. **基准已高度饱和**：YOLO12s 基线 mAP50 = 88.27 / 88.43（两次独立训练），全表 39 组实验中**没有任何一组达到 +1.0 mAP50 的既定标准**。当前最好的 Focaler-CIoU 仅 +0.31（相对双基线均值 88.35）。
2. **训练噪声带已经量化**：两次完全相同的基线训练差异为 ΔmAP50 = 0.16、ΔRecall = 0.93、ΔPrecision = 0.33。所有宣称"有效"的改进（+0.03 ~ +0.31）均落在噪声带的 0.2~2 倍之间，**单次实验无法区分真实增益与随机波动**。
3. **"COCO 预训练迁移失败"只是次要因素，不是结构改进失败的主因**。证据链：① 数据集有 10707 张训练图，YOLOv26s 从零训练与 COCO 预训练仅差 0.05 mAP50——在此数据规模下预训练收益本身很小，"损失一半迁移权重"不足以解释 -0.2~-1.8 的下降；② SPDConv 迁移率高达 99% 却崩溃 -7.3；③ A2C2f 系列注意力变体迁移率 77~80% 仍失败，真实原因是参数量被削减 26~31%（误删了 YOLO12 核心的 Area-Attention 容量）。迁移率与性能的相关性存在，但混杂变量是"结构与预训练拓扑的距离"。
4. **损失函数改进有效的机理**：零结构改动 → 100% 权重迁移 + 容量完全一致，且 Focaler/PIoU 的聚焦机制恰好针对饱和基准上的残余难例。但收益上限约 +0.3，单独调回归损失已接近天花板。
5. **双改进出现负协同**：Focaler-CIoU-DySample（88.28）< Focaler-CIoU 单改进（88.66），WIoUv3-DySample、PIoU2-DySample 同样低于各自最优单改进。饱和基准上叠加两个低增益组件只会放大方差。
6. **下一步方向（文献支撑 + 与现有损失可组合）**：① 特征知识蒸馏（CWD/MGD，教师 YOLO12x/l，+1.9~2.5 mAP50 的同类农业场景证据）；② Soft-NMS/DIoU-NMS 后处理（零训练、直击密集遮挡漏检，Recall 优先的最短路径）；③ NWD 辅助损失（仓库已实现 `nwd` 开关，建议改"替换"为"加权融合"并保留预训练加载）；④ 训练配方升级（多尺度训练、遮挡场景 Copy-Paste、3 种子重复）。组合预期 +0.8 ~ +1.5 mAP50。

- **这不是小目标数据集**：仅 ~12% 实例属于 COCO 小目标，中位数框约 70×70px。P2 高分辨率检测头（stride-4）对应的 <20px 目标占比很小，"加 P2 提小目标"的动机与数据分布不匹配，且 FLOPs 增加 32%（21.5→28.4G）。

### 3.3 关键观察

1. **Recall 优先视角下，现状并不乐观**：全表最高 Recall 是基线 run1 的 82.27。所有"有效"改进的 ΔR 在 −0.96 ~ +0.00 之间——**没有任何方案真正提升了召回**，它们主要靠提升 Precision/定位质量（mAP75）换取 mAP50。这与"漏检代价更高"的任务目标相反，是下一步选型的核心约束。
2. **PIoU2 是定位质量最优解**：ΔmAP75 = +0.61、ΔmAP50-95 = +0.23 全场第一（其角点距离 + 非单调聚焦机制直接优化紧致框）。与 DySample 组合后 mAP75 进一步 +0.68，但 Recall 掉 −0.96，违背任务目标。
3. **300 epoch 不解决问题**：基线 300e（88.32）反而略低于 150e（88.43），说明不是欠拟合，而是基准/数据上限约束。
4. **MultiScaleGatedAttn（+0.06）代价失衡**：参数 +45%（13.46M）、FLOPs +38%（29.81G），收益在噪声带内，剔除。

## 4. 原因分析

### 4.1 迁移假说的系统检验

从 17 个训练目录的 `train.log` 提取的 `Transferred X/Y items` 权重迁移记录：

| 方案 | 迁移率 | ΔmAP50 | 说明 |
|---|---|---|---|
| 损失类（Focaler/PIoU2/WIoU/SD/NWD） | 100% | +0.0~+0.31 | `YOLO('yolo12s.pt')` 直接加载 |
| SPDConv | **99.0%** (684/691) | **−7.30** | 反例①：迁移几乎无损却崩溃 |
| DySample | 98.3% (685/697) | +0.03 | 局部替换，侵入最小 |
| FreqFusion_up | 96.3% (685/711) | +0.06 | 仅替换上采样 |
| A2C2f_EMA / MCA | 80.5% (421/523) | −0.33 / −0.28 | 反例②：高迁移仍失败（容量削减） |
| A2C2f_Mona | 76.9% (445/579) | −0.19 | 同上 |
| A2C2f_MoCA | 76.6% (292/381) | −1.76 | 同上（且幅度更大） |
| Mona（主干） | 77.9% (370/475) | −1.19 | 同上 |
| A2C2f_SCSA | 61.4% (298/485) | −1.50 | 迁移+容量双重打击 |
| P2 / P2-DySample | 55.5% / 54.9% | −0.34 / −0.42 | 新增层无法迁移 |
| BiFPN | 53.5% (414/774) | −0.24 | 拓扑重写 |
| EMA（主干） | 49.1% (342/697) | −0.32 | 拓扑重写 |
| FreqFusion（完整） | 46.9% (342/729) | −0.72 | 拓扑重写 |
| A2C2f_FCM | 46.6% (335/719) | −0.80 | 拓扑重写 |

**结论：假说部分成立，但权重不足。**

- 成立的部分：迁移率 <60% 的方案（BiFPN/EMA/FreqFusion 全量/FCM/P2）全部失败，且这些方案同时重写了 Neck 拓扑——COCO 预训练权重是针对原生 FPN 拓扑优化的特征，拓扑重构后保留的权重失去了原有的协同上下文，等效于"半随机初始化 + 更差的归纳偏置"。
- 不成立的部分（三个反例）：
  1. **SPDConv 迁移率 99% 却 −7.3**：说明失败源于模块本身与优化过程（空间转深度改变了下采样的感受野/梯度通路，且 CSV 中 GFLOPS 记录为 0.00，提示集成或测量环节可能还有配置问题），与迁移无关；
  2. **A2C2f 系列迁移率 77~80% 却一致失败**：真实原因是这批变体把 YOLO12 的核心 A2C2f（Area-Attention）替换为通用注意力（Mona/EMA/MCA/MoCA/SCSA），参数量从 9.25M 掉到 6.4~6.9M——**这不是"增加注意力"，而是"删除 YOLO12 的差异化机制并削减 26~31% 容量"**，属于不公平对照；
  3. **YOLOv26s 从零 vs 预训练仅差 0.05**：在 10.7k 训练图规模下，COCO 预训练的整体收益本身就在 0.1 量级以内，"损失一半迁移"的代价上限撑不起 -0.2~-1.8 的观测下降。
- 总判定：**"结构改动幅度（与预训练拓扑的距离 + 容量变化 + 与数据分布的匹配度）"是失败主因，权重迁移中断是它的伴生症状而非独立原因。**

### 4.2 损失函数改进为何有效（以及为何只有 +0.3）

- **对照绝对公平**：`YOLO('yolo12s.pt')` 保证 100% 权重迁移、9.25M 参数与 21.52 GFLOPs 分毫不差，唯一的变量是损失——这是全部实验中唯一满足"控制变量"的组合。
- **聚焦机制与饱和基准匹配**：Focaler-CIoU（arXiv:2401.10525）对中等难度回归样本加权，PIoU（Neural Networks 期刊）用角点最小化 + 非单调聚焦机制直接优化定位紧致度。当基线已达 88.4 mAP50，剩余误差集中在难例（遮挡/密集/边缘幼苗），聚焦型损失正好"收割"这部分——证据是 PIoU2 的增益集中在 mAP75（+0.61）与 mAP50-95（+0.23），即框更紧了。
- **天花板明显**：回归损失只能优化"已检出目标"的框质量，无法找回"未检出"的目标。WIoUv3、SD_Loss 均在噪声带内，说明在 IoU 族损失内部继续换式的边际收益已耗尽。**要提升 Recall/mAP50 的下一档，必须换杠杆。**

### 4.3 结构改进失败的四种分型

| 分型 | 方案 | 机理 |
|---|---|---|
| ① 拓扑重写型 | BiFPN、FreqFusion 全量、FCM、EMA 主干 | 重构 Neck/主干连接，迁移率跌至 47~53%，保留权重失去协同上下文；单类同质纹理数据上，融合方式的差异本就缺乏信息增益空间 |
| ② 减容量型 | A2C2f_Mona/EMA/MCA/MoCA/SCSA、Mona 主干 | 替换 A2C2f 等于删除 Area-Attention，参数 −26~39%；用更小的模型跑出 −0.2~−1.8，不能归咎于"注意力无效"，而是不公平对照 |
| ③ 数据不匹配型 | P2、P2-DySample | 仅 12% 小目标，P2 的 stride-4 特征面对的是占比很小的问题子集，却带来 +32% FLOPs 和额外的正样本分配扰动（TAL 在高分辨率网格上的尺度歧义） |
| ④ 优化崩溃型 | SPDConv | 迁移率 99% 排除迁移因素；SPD 替换跨步卷积后训练动态被破坏（GFLOPS 记录为 0.00 亦提示集成异常，建议检查 parse_model 注册与测试管线后再下结论） |

### 4.4 双改进的负协同

DySample 参与的全部三个双改进（Focaler-CIoU-DySample 88.28 / WIoUv3-DySample 88.26 / PIoU2-DySample 88.49）都低于各自更优的单改进（88.66 / 88.37+88.43 / 88.54）。机理：DySample 的动态偏移引入参数化随机性，损失函数改动又重塑了梯度 landscape，两者在饱和基准上叠加的方差超过了各自 <0.3 的期望增益。**教训：在噪声带 0.16 的基准上，"0.1 + 0.1 ≠ 0.2"，需要一次只动一个正交维度。**

## 5. 下一步改进方案（文献支撑 × 可与现有损失组合 × Recall 优先）

选型原则：不破坏 COCO 权重迁移（保持 100% 或不影响）、参数/FLOPs 基本持平、直接针对漏检（FN）、有农业场景顶刊先例、可与 Focaler-CIoU / PIoU2 叠加。

### 方案 R1：特征知识蒸馏（CWD / MGD，推荐指数 ★★★★★）

- **做法**：先用 SSDC-UAV 微调 YOLO12x（或 12l）作为教师；学生 = YOLO12s + Focaler-CIoU，在 Neck 的 P3/P4/P5 特征上加 CWD（通道分布 KL 对齐，T=4）或 MGD（随机遮蔽学生特征、生成式恢复教师特征）蒸馏损失。
- **文献证据**：
  - CVPPA@ICCV 2025 甜菜田除草工作：YOLO11x → YOLO11n，**CWD +2.5、MGD +1.9 mAP50**，5 种子重复，学生复杂度零增加（arXiv:2507.12344）；
  - StomaYOLO（玉米气孔检测）：MGD 蒸馏损失最优，mAP 91.8%；
  - 蒸馏在农业检测中已被广泛验证（水稻田杂草 YOLOv8n-DT、UAV 除草分割等）。
- **为何契合本任务**：学生结构完全不变 → **100% COCO 迁移保留**（规避 4.1 的全部失败模式）；教师把密集幼苗场景的特征判别性直接注入学生，主攻"未检出"目标 → 正对 Recall 短板；论文叙事干净（"轻量化 s 模型 + 大模型知识 + 损失聚焦"三要素正交）。
- **实现路径**：本仓库（8.4.60）无内置蒸馏，需自实现——训练脚本中加载冻结教师，注册 forward hook 取双方 Neck 三层特征，`L_total = L_task + λ·L_MGD/CWD`（MGD: mask ratio 0.5~0.65；CWD: T=4, λ≈50 起）。工作量 1~2 天。
- **预期**：+0.8 ~ +1.5 mAP50（教师质量决定上限），是所有方案中唯一单独接近 +1.0 目标的。

### 方案 R2：Soft-NMS / DIoU-NMS 后处理（推荐指数 ★★★★★，零训练成本）

- **做法**：将 NMS 的硬抑制改为置信度衰减（Soft-NMS, σ=0.5）或 DIoU-NMS；先在**现有已训好的最优权重上直接重测**，一天内出结果。
- **文献证据**：
  - 《农业工程学报》2025 密集猕猴桃花期检测（YOLOv8-KFP）：DySample + SSFF/TFE + **Soft-NMS** 组合，P +4.9 / **R +5.1** / mAP50 +3.8，明确将 Soft-NMS 用于"减少遮挡重叠目标候选框误删"；

1. **固定 Δ 基准**：以双基线均值（或 3 seeds 均值）为唯一参照，不再与"更好的一次基线"或"更差的一次基线"选择性比较。
