1. 执行摘要

核心事实基准 mAP50 已达 88.35（双基线均值），全表 39 组实验中没有任何一组达到 +1.0 mAP50 的既定标准；最好的 Focaler-CIoU 仅 +0.31。
  1. 基准高度饱和：两次独立基线训练（88.27 / 88.43）证明训练噪声带为 ΔmAP50 = 0.16、ΔRecall = 0.93。所有"有效"改进（+0.03 ~ +0.31）均在噪声带 2 倍以内，单次实验无法区分真实增益与随机波动。
  2. "COCO 迁移失败"只是次要因素：① 数据集 10707 张训练图，YOLOv26s 从零 vs 预训练仅差 0.05 mAP50，预训练收益本身量级很小；② SPDConv 迁移率 99% 却崩溃 −7.3；③ A2C2f 系列迁移率 77~80% 仍失败，真实原因是参数量被削减 26~31%（误删 YOLO12 核心的 Area-Attention）。相关性存在，但混杂变量是"结构与预训练拓扑的距离 + 容量变化"。
  3. 损失改进有效的机理：零结构改动 → 100% 迁移 + 容量完全一致，且聚焦机制恰好针对饱和基准的残余难例（PIoU2 的 mAP75 +0.61 即证据）。但收益上限约 +0.3，回归损失内部换式已到天花板。
  4. 双改进负协同：Focaler-CIoU-DySample（88.28）< Focaler-CIoU 单改进（88.66），WIoU/PIoU2 与 DySample 的组合同样低于各自最优单改进。
  5. Recall 视角警讯：全表最高 Recall 是基线 run1 的 82.27，所有"有效"改进 ΔR ∈ [−0.96, +0.00]——没有任何方案真正提升召回，与"漏检代价更高"的任务目标相悖，是下一步选型的核心约束。
下一步主线① 特征知识蒸馏（CWD/MGD，同类农业场景 +1.9~2.5 mAP50 证据）→ ② Soft-NMS/DIoU-NMS 后处理（零训练、直击密集遮挡漏检）→ ③ NWD 辅助损失（仓库已实现，建议保留预训练 + 加权融合用法）→ ④ 训练配方升级（多尺度、Copy-Paste、3 种子）。组合预期 +0.8 ~ +1.5 mAP50。

三个关键推论

  • 这不是小目标数据集：仅 ~12% 实例为 COCO 小目标，中位数框约 70×70px。P2 头（stride-4）对应的 <20px 目标占比很小，且 FLOPs +32%（21.5→28.4G）——"加 P2 提小目标"的动机与数据分布不匹配。
  • 数据量足够大：10.7k 图 + 66k 实例下，从零训练也能逼近预训练水平（YOLOv26s 实测 86.56 vs 86.61）——直接限制"迁移失败损失"的量级上限。
  • 密集遮挡是真实痛点：平均 6.2~6.6 株/图、单类同质纹理，重叠遮挡下的漏检是残余误差主要来源——恰好指向 NMS 后处理与蒸馏两个方向。

4. 原因分析

4.1 迁移假说的系统检验（来自各实验 train.log 的 Transferred X/Y 记录）

结论假说部分成立，但权重不足。成立部分：迁移率 <60% 的方案全部失败——这些方案同时重写了 Neck 拓扑，保留的 COCO 权重失去协同上下文。不成立部分（三个反例）：① SPDConv 迁移 99% 崩溃 −7.3（模块/优化问题，GFLOPS 记录 0.00 亦提示集成异常）；② A2C2f 系 77~80% 迁移仍败——真实原因是把 YOLO12 的核心 Area-Attention 替换为通用注意力并削减 26~31% 参数，属不公平对照；③ YOLOv26s 从零 vs 预训练仅差 0.05——10.7k 图规模下预训练整体收益本就在 0.1 量级内，撑不起 −0.2~−1.8 的下降。总判定：结构改动幅度（拓扑距离 + 容量变化 + 数据匹配度）是失败主因，迁移中断是伴生症状而非独立原因。

4.2 损失函数改进为何有效（以及为何只有 +0.3）

  • 对照绝对公平：100% 权重迁移、9.25M 参数、21.52 GFLOPs 分毫不差，唯一变量是损失——全部实验中唯一满足控制变量的组合。
  • 聚焦机制与饱和基准匹配：Focaler-CIoU（arXiv:2401.10525）对中等难度回归样本加权；PIoU（Neural Networks）以角点最小化 + 非单调聚焦直接优化定位紧致度。基线 88.4 后残余误差集中在难例，聚焦型损失正好收割——证据：PIoU2 增益集中于 mAP75（+0.61）与 mAP50-95（+0.23），即"框更紧了"。
  • 天花板明显：回归损失只能优化"已检出目标"的框质量，无法找回"未检出"的目标。WIoUv3、SD_Loss 均在噪声带内——IoU 族内部换式的边际收益已耗尽，提升 Recall/mAP50 的下一档必须换杠杆。

4.3 结构改进失败的四种分型

分型方案机理
① 拓扑重写型BiFPN、FreqFusion 全量、FCM、EMA 主干重构 Neck/主干连接，迁移率跌至 47~53%，保留权重失去协同上下文；单类同质纹理数据上融合方式差异缺乏信息增益空间
② 减容量型A2C2f_Mona/EMA/MCA/MoCA/SCSA、Mona 主干替换 A2C2f 等于删除 Area-Attention，参数 −26~39%；用更小模型跑出 −0.2~−1.8，不能归咎"注意力无效"，而是不公平对照
③ 数据不匹配型P2、P2-DySample仅 12% 小目标，stride-4 特征面对的子集很小，却带来 +32% FLOPs 与 TAL 高分辨率网格上的尺度歧义
④ 优化崩溃型SPDConv迁移率 99% 排除迁移因素；SPD 替换跨步卷积后训练动态被破坏（GFLOPS=0.00 亦提示集成/测量异常，建议复查后再宣判）

4.4 双改进的负协同

DySample 参与的全部三个双改进（88.28 / 88.26 / 88.49）均低于各自更优的单改进（88.66 / 88.43 / 88.54）。机理：DySample 动态偏移引入参数化随机性，损失改动又重塑梯度 landscape，两者在饱和基准上叠加的方差超过各自 <0.3 的期望增益。在 0.16 噪声带的基准上，"0.1 + 0.1 ≠ 0.2"，一次只动一个正交维度。

5. 下一步改进方案（文献支撑 × 可与现有损失组合 × Recall 优先）

选型原则：不破坏 COCO 权重迁移、参数/FLOPs 基本持平、直接针对漏检（FN）、有农业场景顶刊先例、可与 Focaler-CIoU / PIoU2 叠加。

R1特征知识蒸馏（CWD / MGD，教师 YOLO12x/l）★★★★★
  • 做法：先用 SSDC-UAV 微调 YOLO12x/l 作教师；学生 = YOLO12s + Focaler-CIoU，在 Neck P3/P4/P5 特征上加 CWD（通道分布 KL 对齐，T=4）或 MGD（随机遮蔽学生特征、生成式恢复教师特征）。
  • 文献证据：CVPPA@ICCV 2025 甜菜除草：YOLO11x→YOLO11n，CWD +2.5 / MGD +1.9 mAP50，5 种子，学生复杂度零增加；StomaYOLO（玉米气孔）：MGD 蒸馏最优，mAP 91.8。
  • 为何契合：学生结构完全不变 → 100% COCO 迁移保留（规避 4.1 全部失败模式）；教师把密集场景判别性注入学生，主攻"未检出"目标 → 正对 Recall 短板；论文叙事正交干净。
  • 实现：仓库 8.4.60 无内置蒸馏，需自实现——冻结教师 + forward hook 取双方 Neck 特征，L = L_task + λ·L_distill（MGD mask 0.5~0.65；CWD T=4、λ≈50 起），工作量 1~2 天。
  • 预期：+0.8 ~ +1.5 mAP50，唯一单独接近 +1.0 目标的方案。
R2Soft-NMS / DIoU-NMS 后处理★★★★★（零训练成本）
  • 做法：NMS 硬抑制改为置信度衰减（Soft-NMS σ=0.5）或 DIoU-NMS；先在现有最优权重上直接重测，一天出结果。
  • 文献证据：《农业工程学报》2025 密集猕猴桃花期（YOLOv8-KFP）：DySample+SSFF/TFE+Soft-NMS，P +4.9 / R +5.1 / mAP50 +3.8，明确用于"减少遮挡重叠目标候选框误删"；SOD-YOLO（UAV 小目标）：Soft-NMS 降低 FN；UAV 影像增强 YOLOv8：MPDIoU+Soft-NMS 组合 mAP@0.5 +7.6%。
  • 为何契合：平均 6.3 株/图、单类同质、幼苗重叠密集——传统 NMS 误删正是漏检的直接来源；与损失函数组合逻辑自洽：Focaler/PIoU2 把框修紧（IoU 提高）→ 衰减时相邻真框更少被误杀 → P、R 同时受益。
  • 代价：推理时间 +5~15%，无训练成本、无迁移风险；论文中补充推理速度说明。
  • 预期：密集场景 R +0.5 ~ +1.5，mAP50 +0.3 ~ +0.8，可与 R1 叠加。
R3NWD 辅助损失（仓库已实现，建议调整用法）★★★★☆
  • 现状：nwd / nwd_c / nwd_alpha 开关已实现；re0 脚本计划从零训练做 E1 消融。
  • 修正两点：① 保留 COCO 预训练加载——NWD 是损失改动，本可 100% 迁移，从零训练白白引入方差且与其它实验不可比；② 改"替换 CIoU"为"加权融合"：L = (1−α)·Focaler-CIoU + α·NWD-RKL，α 从 0.2 起扫，nwd_c 取 8~12（640 分辨率）。
  • 文献证据：NWD（arXiv:2110.13389）已在无人机小目标（Sci. Rep. 2025：NWD+动态加权）、遥感（YOLO-FNC：NWD+GIoU 融合）、工业微米缺陷等多方向验证。对本数据集 12% 小目标 + 密集框抖动敏感的幼苗是合理补充。
  • 预期：+0.2 ~ +0.5 mAP50，小目标子集 Recall 改善更明显。
R4训练配方升级（常被低估的免费增益）★★★★☆
  • 3 种子重复（方法论刚需）：报 mean±std，否则 ±0.16 噪声带内排序不可信，审稿人必问。
  • 多尺度训练（scale 0.5~1.5）：幼苗尺度跨度大（8.9%~28.8% 大目标），通常 +0.2~0.5。
  • 面向遮挡的增强：Copy-Paste（同类幼苗粘贴模拟密集重叠），直接制造"密集漏检"训练压力。
  • 公平性修正：A2C2f 系列若继续，必须补参数量对齐组（width 放大补回 26% 参数），否则结论无效。

6. 方法论改进清单（提升结论可信度）

  1. 固定 Δ 基准：以双基线均值（或 3 seeds 均值）为唯一参照，避免与"更好/更差的一次基线"选择性比较。
  2. 显著性门槛：ΔmAP50 < 0.32（2× 噪声带）标注"噪声带内"，不参与方向性结论。
  3. 对照公平性检查表：每次结构改进记录 Params / FLOPs / 迁移率三项，任何一项偏差 >5% 需补对照。
  4. Recall 专项报告：除 max-F1 点 P/R 外，增加固定置信度（如 conf=0.25）下的 R 与 FN 数，直接对齐"漏检代价高"的业务目标。
  5. SPDConv 复查：GFLOPS=0.00 与 −7.3 的组合更像集成/配置 bug，建议检查 parse_model 注册与 FLOPs 统计管线后再宣判模块死刑。
